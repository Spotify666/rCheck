# Hyderabad rental shortlist

2 and 3 BHK rentals for a family of four in Himayatnagar, Narayanguda, Kachiguda, Ashok Nagar, VST, Gandhi Nagar, Kavadiguda and RTC X Roads, collected from NoBroker, SquareYards and RealEstateIndia on 26 Oct 2026.

- `site/index.html`: the shortlist page (open it in a browser). It covers listings whose photos show an Indian-style toilet, clean listings to ask about, the full filterable list, and a checklist for the visit.
- `site/finder.html`: a compact, phone-friendly version with tap filters and copy buttons (as a message or spreadsheet rows).
- `listings.csv`: all 197 listings with rent, deposit, size, floor, water, lift, power backup, owner name, link, whether an Indian-style toilet appears in the photos, and a condition note.

Phone numbers are not included: both sites show them only to logged-in users ("Get Owner Details" on NoBroker, "View Number" on SquareYards).
